# Book Management System

A simple React-based Book Management System that allows users to:

- View books
- Add new books
- Edit existing books
- Delete books
- Search books by title or author
- Filter books by genre

The application uses **React**, **Vite**, **Axios**, and **MockAPI** for API integration.

---

# Features

- CRUD Operations (Create, Read, Update, Delete)
- Search functionality
- Genre filtering
- API integration using MockAPI
- Loading and error handling
- Responsive UI

---

# Tech Stack

- React
- Vite
- Axios
- MockAPI
- CSS
